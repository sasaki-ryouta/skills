# レポートの書式と項目別の観点

## 評価項目

| # | 項目（評価アプリの文言） | 短縮名 |
|---|---|---|
| 1 | 仕事の責任を自覚し、常にお客様第一の姿勢で仕事を行ったか（役割を果たす） | 責任・お客様第一 |
| 2 | 会社や上司の方針に素直に従っているか部下に正しく指導しているか | 方針・指導 |
| 3 | 仕事遂行上の工夫改善や能率向上に努めたか（カイゼン） | カイゼン |
| 4 | 上司や同僚との仕事上の報告や連絡・相談は的確にあったか（悪い相談もする） | 報連相 |
| 5 | 職場の雰囲気をあかるくすることに努めたか（あいさつ・コミュニケーション） | 職場の雰囲気 |

採点基準（上司評価・6 段階）: 5 優れている / 4 やや優れている / 3 標準 / 2 やや劣る / 1 劣る / 0 問題外。

## 項目別の観点

- **1 責任・お客様第一** — 顧客（朝田建設様など）や現場への納期と品質。本番前の確認を自分から増やしたか。問い合わせ・不具合への応答の速さ。引き受けた予定を守ったか。
- **2 方針・指導** — 上位者の方針を受けた後の動き（同日に Issue 化・返答したか）。メンバーへの仕組みの配布、講座・周知、レビュー。指導を受けたときの是正。会議への出席。
- **3 カイゼン** — 費用削減・時間短縮・再発防止を数字つきで。前月の課題を解決したか。開発チームの外の業務改善があるか（上司の評価はこちらに寄る傾向）。
- **4 報連相** — 悪い報告を自分から早く出したか。依頼文の明確さ（目的・影響・設定値）。完了報告。依頼を最後まで閉じたか。
- **5 職場の雰囲気** — 朝礼・環境整備・懇親会への参加と発起。感謝や称賛の言葉。全社スペースでの発信。Chat の発言数と、そのうち業務の発信の割合。
