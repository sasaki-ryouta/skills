# decision-sheet

裁定シートは、人の裁定が要る論点を HTML アーティファクトに並べ、裁定を JSON で受け取って作業に戻すための往復である。エージェントが論点と案を立てて公開し、人がシートで裁定して JSON を会話に貼り、エージェントがそれを処理先に落とす。

## ブランチ

- **作る** → [CREATE.md](CREATE.md)。人の裁定が要る論点が2つ以上あるとき、または見ないと決められない論点（画面の形や見た目）が1つ以上あるとき。
- **受け取る** → [RECEIVE.md](RECEIVE.md)。会話に `"schema": "decision-sheet/1"` の JSON が貼られたとき。

論点が1つで、言葉だけで決められるなら、チャットで選択肢を出して聞く。

## 用語

| 語 | 意味 |
| --- | --- |
| 裁定 | 論点ごとに人が下す決定。シートで選び、JSON の `decision` で返る |
| 論点 | 1つの問い。シートの1区画 |
| 案 | 論点への答えの候補。key は `A`・`B`・`C`… |
| 現状 | 今のまま。形と細部の論点には必ず置き、key は `current` |
| 推奨 | エージェントの見立て。論点ごとに1つ、理由を1文添える |
| 見る／決める | タブで案を切り替えるのが見る、右の欄で選ぶのが決める。見るは裁定に数えない |
| 対照 | 比べる1点だけを変え、ほかをすべてそろえる案の作り方 |
| ラウンド | 同じ話題の第2弾以降のシート |
| 外枠 | プロジェクトのアプリの見た目。各リポジトリの `docs/decision/chrome.html` |

論点は3種類ある。JSON の `kind` と TOPICS の `kind` はこの英語名を使う。

| 種類 | `kind` | 中身 |
| --- | --- | --- |
| 形の論点 | `shape` | 何の形にするか。案はレイアウトや情報の階層から違う |
| 細部の論点 | `detail` | 決まった形の中の選択。案は対照で作る |
| 対比の論点 | `contrast` | 設計と今の実装の食い違い。モックはなく、設計と実装の文を並べる |
